# Установка

1. Распакуйте архив **в папку проекта** `DostavkaObedov` (в проводнике: «Извлечь все», в поле пути выберите папку проекта) и согласитесь на замену файлов.
   Папку `vendor` (Laravel) и `.git` трогать не нужно: они остаются как были.
2. Откройте терминал в папке проекта и выполните:
   ```powershell
   .\setup.ps1
   ```
   Если PowerShell запрещает запуск скриптов, один раз выполните `Set-ExecutionPolicy -Scope Process Bypass` и повторите.
3. Запустите сайт: `php artisan serve --port=8000` и откройте `http://127.0.0.1:8000`.

Что делает `setup.ps1`:
- переносит старый статический сайт и лишние файлы из корня в папку `_trash_old` (потом её можно удалить);
- создаёт или обновляет `.env` (язык `ru`, файловые сессии, SQLite, настройки заявок);
- запускает `composer dump-autoload` (или `composer install`, если нет папки `vendor`);
- создаёт ключ приложения и базу `database/database.sqlite`, применяет миграции (таблица `leads`);
- запускает автотесты.

## Проверка
- Откройте `/`, `/menu`, `/promo`, `/services`, `/jobs`, `/en`, `/en/menu`. Адрес `/menu.html` должен перенаправлять на `/menu`.
- Отправьте форму «Обратный звонок» и форму на странице услуг: заявка появится в `php artisan leads:list`.

## Порт 8080 (Apache из XAMPP)
Направьте `DocumentRoot` виртуального хоста на папку `public` проекта (см. прошлую инструкцию) или остановите Apache и запустите `php artisan serve --port=8080`.

## Bootstrap и поиск по меню
- Bootstrap 5.3.3, только сетка (`bootstrap-grid.min.css`, CDN jsDelivr), размечает поля формы заявки на странице услуг. Без интернета скачайте файл в `public/vendor/` и поменяйте ссылку в `resources/views/layouts/app.blade.php`.
- Поиск и фильтр меню: `public/menu-filter.js`, подключается только на странице меню.
